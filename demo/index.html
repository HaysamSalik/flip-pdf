flip-pdf

A PDF that turns like a book

An open-source viewer that renders each page with PDF.js and turns it with a curved WebGL sheet. Drag the corner, swipe, or use the arrow keys.

This page needs a local server: opened from file://, the browser blocks module scripts and the PDF fetch. Run npm start in the project folder, then open http://127.0.0.1:8099/demo/.

Loading. Drag horizontally to turn, click a side to step, or press the arrow keys.

Fits the column, not just the row

The viewer measures its own container, so a col-5, a card or a sidebar is enough. The pages scale to that width, and below 720px the spread collapses to a single page on its own.

Size it with CSS, not with the plugin:

.card { width: 380px; height: 440px; }

<div class="card">
  <div data-flip-pdf
       data-src="book.pdf"
       style="height: 100%"></div>
</div>

Give it a height and the book fills that box at whatever width the column gives. With no height at all it falls back to 240px; --fp-min-height: 0 removes even that fallback so a short card never overflows.

Use it

One script tag, one element with a data-src. Everything else is optional.

<script src="dist/flip-pdf.js" defer></script>

<div data-flip-pdf data-src="book.pdf" style="height: 620px"></div>

Or drive it yourself

The class is exported for bundlers and exposes the same controls the chrome uses.

import { Flipbook } from "flip-pdf";

const book = new Flipbook(el, { mode: "double" });
await book.load("/book.pdf");

book.next();
book.goToPage(9);
book.on("pagechange", ({ spread }) => {});

What the sheet actually does

  • Curved, not rotated. The leaf is integrated as an arc from the spine, so segment length is preserved and the page foreshortens instead of stretching.
  • Lit by its own normal. A flat page renders at exactly full brightness; the turning sheet darkens only where it faces away from the light.
  • Two textures per sheet. The front and back are separate pages, mirrored on the back so the arriving page reads correctly.
  • Camera pulls back mid-turn, which is what keeps the swinging edge inside the frame.

What it does not do

  • No text selection or search. Pages are rasterised to textures.
  • No annotation layer. Form fields and links inside the PDF are not interactive.
  • No server. The PDF is fetched by the browser and rendered locally; nothing is uploaded.
  • No fallback for encrypted files beyond PDF.js's own password prompt hook.
