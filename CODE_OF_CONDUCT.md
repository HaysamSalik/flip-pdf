# Code of Conduct

## Scope

This applies to issues, pull requests, discussions and any other space where
people work on this project.

## Expected behaviour

- Be direct about code and kind about people. "This clips at 320 px, here is the
  frame" is useful. "This is obviously broken" is not.
- Assume the person you are replying to read the code before commenting. If they
  did not, point at the line.
- Accept that a maintainer may decline a change for scope reasons. A rejected
  pull request is a decision about the project, not about you.
- Give credit where it is due, especially for reproductions and for finding the
  cases that broke.

## Unacceptable behaviour

- Harassment, intimidation, or sustained disruption.
- Insults, personal attacks, or comments about someone's identity, background or
  level of experience.
- Sexualised language or imagery, in any project space.
- Publishing someone's private information without their permission.
- Dismissing a report of the above.

## Enforcement

Report a problem by opening a private report through the repository's Security
tab (Report a vulnerability) if you need privacy, or by contacting a maintainer
directly. Reports are read by the maintainers and kept confidential.

Maintainers will respond in proportion: a private word for a first offence, then
a warning, then a temporary or permanent ban from the project spaces. A
maintainer who is involved in an incident does not decide its outcome.

## Attribution

This is a short project-specific policy. If you would rather adopt a standard
text, Contributor Covenant 2.1 (<https://www.contributor-covenant.org/version/2/1/code_of_conduct/>)
is a reasonable replacement, and nothing in this file conflicts with it.
